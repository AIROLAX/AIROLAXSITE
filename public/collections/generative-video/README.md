# 3D Generative

Pon aquí renders, stills y frames de motion 3D / generativo.

## Añadir imágenes

1. Copia JPG/PNG/WebP en `index/` (cualquier nombre).
2. En la raíz del repo:

```bash
npm run collections:optimize generative-video
npm run projects:sync
```

3. Recarga el sitio → chip **3D Generative** en el Immersive Index.

Videos opcionales: `previews/01.mp4` + entrada en `video-map.json` (mismo patrón que `ai-content`).
